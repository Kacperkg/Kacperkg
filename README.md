## Featured projects

### [AudiSport](https://github.com/Kacperkg/audisport)
A motorsport website built with **React, TypeScript, TanStack Start, GSAP and Tailwind CSS**. Features scroll-driven animations, a horizontal desktop timeline, a responsive vertical mobile layout and a header that adapts to the content beneath it.

### [Vellum](https://github.com/Kacperkg/vellum)

A full-stack personal-finance application built with **React, TypeScript, Vite, Tailwind CSS, Go/Gin and PostgreSQL**. Features account management, transactions, transfers, budgets, savings goals and financial analytics.

Implemented typed REST API integration, JWT authentication with rotating refresh tokens, account ownership checks and database integrity constraints. Includes automated frontend, backend and Playwright browser tests, with GitHub Actions CI workflows.

### [The Hive](https://github.com/Kacperkg/hive-public)
A workout planner built with **React Native, Expo, TypeScript, Go and PostgreSQL**. Includes workout templates, calendar scheduling, set-by-set tracking, rest timers and a typed API client, alongside backend tests and CI.
